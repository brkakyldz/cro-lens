Failing scenario: while `cro-lens ui` runs on 127.0.0.1:8765, any web page the owner visits sends `fetch("http://127.0.0.1:8765/api/eval/linear-home/labels", {method:"POST", mode:"no-cors", body: JSON.stringify({category:"cta", severity:"high"})})`.
