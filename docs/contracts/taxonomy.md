# taxonomy@1

Shared by model findings and the user's grades (eval@2, `by_category`).
Source: `reports/research/2026-11-10_cro-teardown-practice.md`.

| Category | Covers |
|---|---|
| `value_prop_clarity` | the first screen does not say what it is, for whom, and why it matters |
| `specificity` | generic, interchangeable or superlative copy where a concrete claim is needed |
| `message_match` | page does not match the likely traffic source / ad promise / awareness level |
| `offer` | weak, unclear or mismatched offer (trial, demo, discount, guarantee) |
| `pricing_visibility` | price or plan information missing, hidden or confusing |
| `social_proof` | missing, vague, unattributed or badly placed proof |
| `trust_risk` | security, privacy, refund, company legitimacy, risk-reversal gaps; dark patterns |
| `objection_handling` | visitor's predictable objections left unanswered |
| `cta` | primary action missing, weak, ambiguous, competing, or below the fold |
| `friction_forms` | form length, required fields, steps, sign-up friction |
| `visual_hierarchy_distraction` | attention pulled away from the goal; layout or contrast hides key content |
| `mobile_speed_access` | mobile-specific layout problems, slow load, accessibility barriers |
